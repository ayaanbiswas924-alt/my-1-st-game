GeoDash
Step into a world of fun where gravity shifts with each move. This is a game based on geometry dash. It has similar aspects to geometry dash. There are 10 different levels and a boss level. Travel through the different worlds and collect all the objects in each world.  After each level you beat, you can move on the next level. After beating all 10 levels, you can do the boss level. If you beat this level, you beat the entire game! Each jump is a decision- if you miss it, you're back to square one. Make each decision carefully and wisely.  Can you survive the chaos andd reach the end before the stars fade?
How to play: Use the arrow keys to navigate through the levels and collect all the items from each level. After collecting each level, return to the level basket to put the item in it. do this until all the items are collected and put in the baskets.
